GREEN MIRACLE WEBSITE
=====================

Files:
- index.html: Main website page
- style.css: Layout, colours, responsive design and visual styling
- script.js: Mobile navigation, action checklist and current year

HOW TO PREVIEW ON ANDROID:
1. Extract green_miracle_website.zip using your phone's file manager.
2. Open the extracted folder in an HTML editor such as Acode.
3. Open index.html and use the app's Preview option.
4. You can edit the text, colours and sections in the files.

HOW TO PUBLISH:
Upload the extracted website folder (or its contents, with index.html at the root)
to a static website host such as Netlify or GitHub Pages. Connect your domain
only after you have registered it and configured the host's DNS instructions.

NOTES:
- This is an original starter website built for the Green Miracle project.
- Social links are the exact links supplied by the owner.
- The website does not claim to be a registered charity, NGO or official organisation.
- Review all content and links before publishing.
- Fonts load from Google Fonts when internet access is available; fallback fonts are included.
